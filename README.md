## What changed since the first draft (reviewer notes, Sep 10)

- Reordered: prompting, documents, code, agents and cost, skill docs, build. Foundation in place before quals.
- Attribution and disclosure folded into Session 1. Failure taxonomy and pre-flight folded into Session 2 and every debrief.
- Editing passes folded into Handout 6. Critic moves now run inside the build session as the critique format.
- Tiering, effort, and cost folded into Session 4 with agents.
- Dates added per the agreed schedule. January 7 and 8 held for a topic the group picks.

## Folder layout

- `Full Curriculum.html`, `Full Curriculum.pdf`: the complete document.
- `Full Curriculum (source).md`: plain-text source for edits.
- `00 Overview/`: cover, schedule, assumptions, standing structure, facilitation notes.
- `Session NN - Title/`
  - `Facilitation Plan/`: goal, why, ready-made materials, timed plan, watch-outs. Session 1 also holds the opening deck as a PDF.
  - `Takeaway Guide/`: the one-page participant handout.
  - `Materials/`: the ready-made materials as a PDF, plus a text file of every link.
- `Session 02 Add-on - GitHub 101/`: same three folders. Not yet in `Full Curriculum.html` or the PDF.
