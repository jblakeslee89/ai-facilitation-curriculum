Good and bad commit messages: Bad: update, fixes, asdf. Good: Drop 2019 rows counted twice in the merge, Add Session 1 prompt pair on the GAO summary. One line, starts with a verb, says what changed and, if it isn't obvious, why.

Git-tutor prompt: I'm new to Git and GitHub. Here is exactly what I did and the error I got: [paste]. Explain what happened in plain language, then give me the smallest safe fix. Do not suggest force-push, reset --hard, or deleting the repository.

Something to break on purpose: In the practice repository, edit the same line of the README on two branches, then try to merge both. GitHub shows a merge conflict and a web editor to resolve it. Better to meet one here than in a thesis chapter.
